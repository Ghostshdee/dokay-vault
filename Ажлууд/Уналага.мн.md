төсөл** — өөрийн `CLAUDE.md`, `DESIGN.md`, `BUILD.md`-тэй.

- **Амьд:** одоохондоо байхгүй (статик прототип)
- **Код:** GitHub repo хараахан үүсээгүй
- **Локал:** `Desktop\Claude\Vault\Төслүүд\unalaga\` — vault дотор

Тээврийн 4 төрөл: хүн · мал · бараа · **гэр нүүлгэх**. Сүүлийн хоёр нь
Uber/BlaBlaCar-т байхгүй, зөвхөн Монголд — платформын гол ялгарал.

## Одоогийн байдал — BUILD.md §7-ийн 1-р алхам дууссан (2026-09-07)

гадны сан ашиглаагүй). Машины хэсэг: gradient → хатуу ink + алтан хайрлаас

дүрэм хэвээр (сүүдэргүй карт, багасгасан хөдөлгөөн, 44px хүрэх талбай).

## Гол шийдвэрүүд

**Карт = замын хуудас, Facebook пост биш.** Хамгийн том элемент нь хүний
нэр биш, **чиглэл**. Хоёр хотыг холбосон босоо тасархай шугам, доод цэг
алтан — энэ дизайны онцлог дүрс (`.post-route`), өөр газар давтахгүй.

**Өнгө — сахилгатай (DESIGN §2).** Улаан зөвхөн «Унаа хэрэгтэй» badge,
устгах үйлдэл. «Шинэ захиалга үүсгэх» товч **хөх** болгосон.

**Фонт (DESIGN §3).** Unbounded зөвхөн 2 газар — лого, картын чиглэлийн
нэр. Бусад бүх текст Golos Text (кирилл сайн). Inter-ийг халсан.

**Badge — хүрээтэй чип (DESIGN §5),** дүүргэсэн өнгөт биш. «Унаа хэрэгтэй»
л дүүргэсэн улаан (захиалагчийн постыг ялгана).

**Машины зурагт stock биш байршуулагч.** BUILD §3 Unsplash санал болгосон
ч зургууд машинтай таарахгүй (Prius → Porsche), тогтворгүй ачаалагдана.
Итгэл дээр суурилсан платформд буруу шошготой зураг хортой. Одоо: хөх
дэвсгэр + машины нэр (хурдан ачаална). Бодит зургийг жолооч өөрөө оруулна
(backend). `.post-photo` дотор `<img>` нэмэхэд бэлэн.
