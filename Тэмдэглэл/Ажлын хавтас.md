## Шийдэл — GitHub дамжуулагч болно

Файлыг хоёр машины хооронд зөөх найдвартай зам нь GitHub.
Хувийн ком дээрээ бүгдийг татаж авах:

```bash
cd C:\Users\dulgu\Desktop\Claude
git clone https://github.com/Ghostshdee/Ghostshdee.github.io Code
cd Code
git clone https://github.com/Ghostshdee/dokay-portfolio
git clone https://github.com/Ghostshdee/dokay-ai-service
git clone https://github.com/Ghostshdee/dokay-journeys-onepager
git clone https://github.com/Ghostshdee/urilga-hurim-batbayar-altantsetseg
git clone https://github.com/Ghostshdee/urilga-sevleg-mongolhuu
git clone https://github.com/Ghostshdee/urilga-ongodoo-zalah
```

Ингэснээр хувийн ком дээр яг ижил бүтэц үүснэ. Дараа нь тэндээсээ
`git push` хийвэл амьд хаяг шинэчлэгдэнэ.

Шаардлагатай: `git` + `gh` суусан байх. Шалгах:

```bash
git --version
gh auth status
```

`gh` нэвтрээгүй бол: `gh auth login`
