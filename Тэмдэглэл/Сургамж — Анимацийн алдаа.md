# Сургамж — Анимацийн алдаа

GSAP-тай сайт бүтээхэд **дахин дахин гарсан** дөрвөн алдаа. Шинэ сайт
эхлэх бүрд эдгээрийг шалгана.

## 1. Далд табд хуудас хоосон үлдэх

Facebook, Messenger-ээс «шинэ табд нээх» гэж дарахад хуудас **далд табд**
ачаалагддаг. Далд табд хөтөч `requestAnimationFrame`-ыг зогсоодог тул
GSAP-ийн анимаци урагшилдаггүй → контент `opacity:0` хэвээр үлдэж,
хэрэглэгч таб руугаа ороход **хоосон хуудас** харна.

Энэ бол Дархны хэрэглэгчдийн хамгийн түгээмэл орох зам тул ноцтой.

**Шийдэл — анимацийг устгах биш, ХОЙШЛУУЛАХ:**

```js
function boot(){
  if (document.hidden){
    revealAll();                    // хоосон дэлгэц гарцаагүй үүсэхгүй
    document.addEventListener('visibilitychange', function once(){
      if (document.hidden) return;
      document.removeEventListener('visibilitychange', once);
      initAnimations();             // таб руу орох агшинд бүрэн эффект
    });
    return;
  }
  initAnimations();
}
```

## 2. `load` аль хэдийн болчихсон байх

`window.addEventListener('load', ...)` нь bfcache-аас буцах, удаан задлалт
зэрэг үед **хэзээ ч дуудагдахгүй**. Заавал шалгана:

```js
if (document.readyState === 'complete') boot();
else window.addEventListener('load', boot);
```

## 3. Үсэг тус бүр `inline-block` → үг дундуур мөр тасарна

Stagger анимац хийхийн тулд үсэг бүрийг span болговол хөтөч **үгийн заагийг
таньдаггүй** бөгөөд «КОНТЕНТ БҮ / ТЭЭГЧ» гэж тасалдаг.

**Шийдэл — үг бүрийг nowrap сав дотор хийнэ:**

```html
<span class="wd"><span class="ch">Б</span><span class="ch">Ү</span>…</span>
```
```css
.wd{ display:inline-block; white-space:nowrap }
.ch{ display:inline-block }
```

## 4. Хэмжээ тааруулагчийг анимацийн ДОТОР бүү тавь

`fitHero()` зэрэг зохион байгуулалт тааруулдаг функцийг `initAnimations()`
дотор дуудвал дараах гурван тохиолдолд **огт ажиллахгүй**:

- хэрэглэгч `prefers-reduced-motion` асаасан
- GSAP ачаалагдаагүй
- хуудас далд табд нээгдсэн

[[Dokay portfolio]] дээр яг ийм болж, гарчиг утсан дээр 176px халиад
тасарч байсан. Анимацаас **салгаж**, `boot()`-д үргэлж дуудагддаг болгосон.
