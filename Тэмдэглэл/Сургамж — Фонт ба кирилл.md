# Сургамж — Фонт ба кирилл

## Дүрэм №1 — олон алдартай condensed фонт кирилл ДЭМЖДЭГГҮЙ

Монгол гарчигт condensed (шахсан) фонт хэрэгтэй болоход хамгийн түрүүнд
санаанд орох нэрс нь **бүгд ажиллахгүй**:

| Фонт | Кирилл |
|---|---|
| Anton | ✗ |
| Archivo Black | ✗ |
| Bebas Neue | ✗ |

Эдгээрийг ашиглавал хөтөч өөр фонт руу унаж, зохион байгуулалт эвдэрнэ.

## Ажилладаг сонголтууд

| Фонт | Мэдрэмж | Кирилл |
|---|---|---|
| **Oswald** | Жинхэнэ condensed, сонины гарчиг маягийн | ✓ |
| **Roboto Flex** | Variable, `wdth` 25–151 тэнхлэгтэй | ✓ |
| Unbounded | Геометр, техно. **Condensed биш** | ✓ |
| Montserrat, Rubik, Manrope, Inter | Энгийн sans | ✓ |
| JetBrains Mono, IBM Plex Mono | Mono | ✓ |

## Дүрэм №2 — variable фонтын тэнхлэгийг тогтоо

Roboto Flex-ийн **бүтэн** variable файл нь кирилл subset дээр **191 KB**.
Бидэнд ганц хэлбэр л хэрэгтэй тул Google Fonts дээр тэнхлэгийг тогтооно:

```html
<!-- МУУ — 191 KB -->
family=Roboto+Flex:opsz,wdth,wght@8..144,25..151,100..1000

<!-- САЙН — 58 KB -->
family=Roboto+Flex:wdth,wght@62,900
```

[[Dokay portfolio]] дээр энэ нь нийт хуудсыг **581 KB → 333 KB** болгосон.

Хэд хэдэн хэлбэр хэрэгтэй бол `;`-ээр нэмнэ:
`Roboto+Flex:wdth,wght@62,900;100,400`

## Дүрэм №3 — фонт ачаалагдсаны ДАРАА хэмжинэ

Гарчгийн өргөнийг JS-ээр тооцох бол `document.fonts.ready`-г хүлээнэ.
Эс тэгвээс fallback фонтоор хэмжиж буруу тоо гарна.

```js
document.fonts.ready.then(() => fitHero());
```
