# Dokay Vault

Dokay-гийн вэб ажлуудын мэдлэгийн сан. **Obsidian vault.**

## Хэрхэн нээх

Obsidian → `Open folder as vault` → энэ хавтсыг сонгоно.
Эсвэл байгаа vault-ынхаа дотор хавтас болгож хуулна.

## Бүтэц

```
Dokay — Нүүр.md        ← эндээс эхэл (MOC)
Хийх зүйлс.md          ← дуусаагүй бүх зүйл
Ажлууд/                ← сайт бүрийн тэмдэглэл
Тэмдэглэл/             ← дахин ашиглах мэдлэг
```

Тэмдэглэлүүд `[[давхар хаалт]]`-аар хоорондоо холбогдсон.
**Graph view** нээвэл бүх холбоос зураглал болж харагдана.
